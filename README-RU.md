# Clean Your TV — русская сборка с рядами фильмов, погодой и VPN

Форк проекта [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) (MIT). Чистка Android TV / Google TV
по сети и домашний экран в стиле Apple TV, доработанный под русские сервисы. Проверено на TCL G07 (Google TV,
Android 11).

## Что добавлено к оригиналу

- **Ряды над панелью приложений**: при наведении на ivi, LazyMedia Deluxe или NUM — «Продолжить просмотр» /
  «История» и **«Новые фильмы»** (популярные фильмы этого и прошлого года из открытого каталога ivi).
  Вверх/вниз переключают ряды, ОК открывает фильм.
- **Фон и описание**: при наведении на фильм — его кадр на весь экран, название, год, рейтинг Кинопоиска и описание
  (для ivi описание подтягивается из каталога ivi).
- **Фильм открывается в своём приложении**: ivi — сразу; LazyMedia — через её поиск (только точное совпадение,
  первый раз ~30 с); NUM — по странице TMDB (номер берётся из Wikidata по номеру Кинопоиска).
- **Погода под часами** (Open-Meteo, запасной MET Norway, если первый заблокирован у провайдера).
- **Библиотека приложений**: на главном экране только панель, всё остальное — за кнопкой с точками.
- **VPN (Incy)**: VPN включается сам при включении ТВ и перед открытием YouTube; значок сети открывает Incy.
- **Steam Link**: геймпад не перехватывается службой кнопок пульта.

## Быстрый способ: через ИИ-ассистента

Откройте [PROMPT-RU.md](PROMPT-RU.md), включите на ТВ отладку по сети и вставьте промпт в Claude Code на
компьютере в той же сети. Ассистент сам почистит ТВ, соберёт и поставит этот домашний экран.

## Вручную

Нужны Python 3, JDK 17 и Android SDK (platform 34, build-tools 34.0.0). Перед сборкой откройте
`launcher/app/src/main/res/values/config.xml` и поставьте свои **приложения на панели** (`dock_apps`),
**координаты города** для погоды (`latitude`, `longitude`) и, если нужно, **VPN-приложение** (`vpn_app`,
`res/values/vpn.xml`). Потом (Windows):

```
launcher\build-and-install.ps1 -TvHost <ip телевизора> -HomeKeyService -RestoreKeyServices
tools\venv\Scripts\python.exe -I tools\tv.py "pm grant com.gathin.tvhome android.permission.READ_TV_LISTINGS"
```

Последняя команда даёт домашнему экрану доступ к рядам «Продолжить просмотр» и каналам приложений — без неё
рядов не будет. Готовый APK есть в разделе Releases (подписан отладочным ключом, ставится по ADB).

Откат: `tools\restore.ps1 examples\<ваша модель>\debloat.txt` возвращает всё, как было.

## Известные ограничения

- Ряды показывают только то, что приложения сами публикуют в систему; «Новые фильмы» — из каталога ivi.
- У NUM в «Новых фильмах» только те фильмы, для которых в Wikidata есть номер TMDB.
- Картинки YouTube грузятся только через VPN (добавьте домашний экран в список приложений VPN).
