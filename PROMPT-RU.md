# Промпт: «Сделай мой Android TV как Apple TV»

Вставьте всё, что ниже линии, в Claude Code (или другого ИИ-ассистента с доступом к командной строке) на
компьютере, который подключён к той же сети, что и телевизор. Подходит для **Android TV / Google TV**
(TCL, Xiaomi, Sony, Hisense, Philips, Haier и др.). Samsung (Tizen) и LG (webOS) не подходят.

**До начала, на телевизоре:** Настройки → Настройки устройства → Об устройстве → 7 раз нажать ОК на «Сборка».
Назад → «Для разработчиков» → включить «Отладка по USB» и, если есть, «Отладка по сети / ADB по сети».
Телевизор не выключать. Когда ассистент попросит, подтвердить на ТВ «Разрешить отладку?» (галочка «Всегда»).

---

Я хочу почистить свой Android TV и поставить красивый домашний экран в стиле Apple TV. Делай всё сам,
шаг за шагом, на настоящем телевизоре, и проверяй каждый шаг снимком экрана с ТВ. Спрашивай меня только
то, что зависит от моих вкусов или требует моего согласия. Общайся со мной по-русски, простыми словами.

## 0. Правила безопасности (обязательно)

- Не принимай за меня лицензии, пользовательские соглашения и окна согласия (Android SDK, RuStore,
  «Разрешить VPN?» и т. п.) — спроси меня или попроси нажать самому.
- Перед любой загрузкой с интернета скажи, что и откуда качаешь, и дождись моего «да».
- Ничего не удаляй с ТВ: только `pm disable-user --user 0`, всё обратимо. Перед изменениями сделай резервную копию.
- Не меняй системные настройки безопасности ТВ. Отладку по сети не закрывай, пока я не скажу, что правки закончены;
  потом выключи её и проверь, что порт 5555 закрыт.

## 1. Подключение

- Найди ТВ в локальной сети (просканируй порт 5555 в своей подсети) и подключись по ADB.
- Если на компьютере нет нужных программ, предложи поставить: Python 3 (если обычный установщик не встаёт —
  портативная «embeddable» версия + pip), JDK 17 (Adoptium), Android command-line tools (Google). Всё ставь
  в одну рабочую папку в моём профиле, например `%USERPROFILE%\cleanyourtv-work`.
- Скачай проект https://github.com/Gathin23/cleanyourtv и прочитай его `PROMPT.md`, `README.md` и
  `examples/<моя модель>/debloat.txt` — это основа. Используй `tools/tv.py` (ADB-клиент на Python).
- Windows: в PowerShell 5.1 кавычки и `|` внутри команды для ТВ ломаются — передавай сложные команды через
  `tools/tv.py --batch` (stdin), русский текст из логов забирай файлом (`logcat ... > /data/local/tmp/x.txt`,
  затем `--pull`). Если сборка падает на `classes.dex ... занят другим процессом` — это антивирус, просто повтори.

## 2. Резервная копия и чистка

- Сохрани список пакетов, отключённых пакетов, `getprop` и все `settings`.
- Отключи мусор по списку из `examples/` для моей модели. Спроси, нужны ли мне голосовой помощник, Chromecast,
  Miracast, обновления.
- Проверь, не отключено ли раньше что-то нужное (например, на TCL `com.tcl.suspension` — кнопка Input,
  `com.tcl.keyhelp` — кнопки пульта). Если отключено — скажи и предложи включить.

## 3. Домашний экран

Собери лаунчер из `launcher/` (`build-and-install.ps1 -TvHost <ip> -HomeKeyService -RestoreKeyServices`),
сделай его домашним, проверь снимками. Затем доработай его (настройки — в `config.xml`, код — в Java):

1. **Панель (док):** спроси 4–5 приложений и порядок. Все остальные приложения убери с главного экрана
   (`hidden_apps`) в **библиотеку приложений** (`app_library`, кнопка `library_button`); в библиотеке ОК должен
   **открывать** приложение, а «добавить на главный экран» — по удержанию ОК.
2. **Плитки чуть меньше:** параметр `tile_max_dp` (у меня 128 вместо 180).
3. **Погода под часами:** иконка, температура и «ясно/пасмурно…». Город определи по часовому поясу ТВ и
   провайдеру и уточни у меня. Источник Open-Meteo; если он не открывается с ТВ (у некоторых провайдеров
   заблокирован) — запасной MET Norway (`api.met.no`, нужен User-Agent). Обновлять раз в 30 минут.
4. **Ряды контента над панелью** (как на Google TV/Apple TV): когда наводишь на приложение в панели, над ним
   появляется ряд карточек. Данные — из системного TV-провайдера (`TvContract.WatchNextPrograms` и
   `PreviewPrograms`), разрешение `READ_TV_LISTINGS` выдай через `pm grant`; читай таблицы целиком без
   selection (см. `docs/watch-next.md`).
   - Для каждого приложения: ряд истории («Продолжить просмотр» / канал «История») и ряд **«Новые фильмы»**.
     Остальные каналы приложений не показывай (у меня так захотелось; спроси, нужно ли иначе).
   - Вверх с панели — в ряд, влево/вправо — листать, вверх/вниз — переключать ряды, над карточками подпись
     «РЯД ▲ СЛЕДУЮЩИЙ РЯД 1/2». Из верхнего ряда вверх — к кнопкам, вниз из нижнего — на панель.
   - Карточки горизонтальные 16:9; вертикальный постер растягивай по ширине и показывай верхнюю часть.
     Полоска прогресса для «Продолжить просмотр».
   - При наведении на карточку: постер этого фильма на весь фон (с затемнением слева и снизу), крупное
     название, год, рейтинг и описание (2 строки). Название приложения и ряд не должны наезжать на погоду и
     панель — подбери размеры и проверь снимком.
   - ОК — открыть фильм: через `intent_uri`, который дало приложение.
   - Подводные камни, на которые я наткнулся: часть обложек идёт по `http` — включи `usesCleartextTraffic`;
     у NUM прокси картинок `tmdb.torrs.ru` бывает мёртв — бери тот же путь `/t/p/...` с `imagetmdb.com` или
     `image.tmdb.org`; картинки YouTube грузятся только через VPN.
5. **Описания для ivi:** ivi не передаёт описание для «Продолжить просмотр». Бери его из открытого API ivi
   (без ключа): `https://api.ivi.ru/mobileapi/search/v7/?app_version=870&from=0&to=0&query=<сериал>`
   (`short_description`/`synopsis`, `years`, `kp_rating`, `ivi_rating_10`). Название сериала — до « - Сезон».
6. **«Новые фильмы»:** ни одно приложение их не публикует, поэтому список бери из каталога ivi:
   `https://api.ivi.ru/mobileapi/catalogue/v5/?app_version=870&category=14&sort=pop&year_from=<год-1>&year_to=<год>&from=0&to=29`
   (картинка `promo_images[0].url`, описание `synopsis`, рейтинг `kp_rating`, `kp_id`). Кэш на 6 часов.
   Как открывать в разных приложениях:
   - **ivi** — `https://www.ivi.ru/watch/<id>` с пакетом ivi.
   - **LazyMedia Deluxe** — через её поисковый провайдер `content://com.lazycatsoftware.lmd.tvsearch/search_suggest_query/<название>`
     (нужен `<queries><provider android:authorities="com.lazycatsoftware.lmd.tvsearch"/>`), брать **только
     точное совпадение названия**, открывать `ACTION_SEARCH` с `data = suggest_intent_data` в
     `ActivityTvArticle`. Поиск идёт ~30 с — запускай заранее, когда фокус задержался на карточке, ответы
     запоминай. Нет совпадения — открыть в ivi.
   - **NUM** — открывает фильм по ссылке `https://www.themoviedb.org/movie/<tmdb_id>` в `DetailsActivity`.
     TMDB-номер находи одним запросом в Wikidata по номерам Кинопоиска (`wdt:P2603` → `wdt:P4947`,
     с User-Agent). Фильмы без номера в ряд NUM не включай.
   - Для других приложений найди способ сам (`dumpsys package <пакет>`: intent-фильтры, поисковые провайдеры)
     и проверь на ТВ, что фильм реально открывается.
7. **VPN (если у меня есть VPN-приложение, например Incy):** спроси, каким VPN я пользуюсь. Для Incy есть
   команды `llc.itdev.incy.CONNECT/DISCONNECT` в `llc.itdev.incy/.receiver.VpnIntentReceiver`. Сделай:
   - значок сети на главном экране открывает VPN-приложение (`vpn_app`), рядом зелёный/красный значок VPN;
   - VPN сам включается, когда появляется главный экран без VPN (после включения ТВ), с повтором через 20 с;
   - при открытии YouTube — сначала подключить VPN, потом открыть YouTube;
   - не выключать VPN, если в VPN-приложении настроено «только для выбранных приложений»; иначе спроси меня.
   - Android разрешение на VPN приложение получает только после моего «ОК» в системном окне — попроси меня.
   - Подскажи мне добавить сам домашний экран («Главный экран») в список приложений VPN — иначе не грузятся
     обложки YouTube.
   - Если при включённом VPN пропадает весь интернет (не открывается даже ya.ru) — это проблема сервера в
     VPN-приложении, скажи мне об этом прямо.
8. **Steam Link / геймпад:** включи `gamepad_passthrough`, чтобы служба кнопок пульта не перехватывала геймпад.
   Помоги подключить геймпад к ТВ по Bluetooth (открой экран «Добавить устройство»).
